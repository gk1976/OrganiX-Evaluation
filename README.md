Agents that draft long, multi-day research reports on top of a persistent, incrementally updated knowledge graph face two compounding problems: (i) context-window blowout, because a naively implemented drafting loop concatenates the entire running transcript into every subsequent generation call, and (ii) section redundancy, because independently prompted sub-agents restate material already covered earlier in the document. We present Hierarchical Outlining with Speculative Context Prefetching (HO-SCP), a drafting method that first expands a manuscript into a nested blueprint (Title → Abstract → Sections → Subsections → Paragraph Intent Vectors), then, while drafting section N, has a retrieval agent speculatively predict and pre-index the graph/vector-store chunks likely required for section N+1 from that section's paragraph intent vectors, and finally restricts each drafting sub-agent to its parent node's intent, its immediate sibling's summary, and the pre-fetched chunks only  never the full transcript. We implement HO-SCP as a LangGraph state graph with per-section checkpointing and provide a deterministic, reproducible proof-of-concept harness comparing HO-SCP against a flat-context, synchronous-retrieval baseline on a six-section synthetic drafting task.
•	Restricts each drafting sub-agent's input to parent-node intent, immediate sibling context, and pre-fetched evidence only, decoupling per-section context size from document length.
•	Hides retrieval latency by issuing speculative prefetch queries for section N+1 concurrently with the drafting of section N, derived from paragraph intent vectors rather than a fixed schedule.
•	Integrates directly with LangGraph's durable-execution and checkpointing primitives, so the outline tree and prefetch cache survive interruption and support human-in-the-loop review between sections.
